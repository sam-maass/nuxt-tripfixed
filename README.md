# nuxt-tripfixed

Server-side-rendered marketing and landing site for **tripfixed** (the later brand of the
flystr flight-deal discovery product). Built with Nuxt 2 and TypeScript, it is the public
front door that showcases current deals and funnels visitors into the web application,
with SSR treated as a first-class requirement for SEO and fast first paint. It is one of
five services in the flystr architecture; for the full multi-repo overview see the pinned
[**flystr**](https://github.com/sam-maass/flystr) repository.
